# ShareWave

## Краткое описание

Проект будет представлять из себя совместный медиаплеер.
Предполагаются следующие возможности:
- Скачивание мультимедиа у контактов при наличии доступа.
- Совместный просмотр мультимедиа со своими контактами.

Упор на P2P.

## Для разработчиков

Окружение — Dev Container (Debian + Clang + CMake + Conan). VS Code сам поднимает контейнер и монтирует код.

Принцип: образ содержит только инструменты. Бинарники библиотек (Boost, OpenSSL, libsodium) хранятся в Docker Volume (sharewave-conan-cache) и переживают пересоздание контейнера и пересборку образа.

При каждом запуске контейнера скрипт entrypoint.sh вызывает conan install --build=missing. Если бинарники уже есть в Volume — Conan использует их. Если нет — собирает и кладёт в Volume.
